# Phorminx 0.2.0

Released 2026-10-17

The first public release: dictation, meetings with live translation, and an
assistant, in a new desktop app that updates itself.

## New

- **New desktop app**: Home, History, Meetings, Actions, Models, Settings and Setup in one window, with light and dark themes.
- **Meeting companion**: a resizable window with Transcript, Together and Assistant views that stays beside your call.
- **Live translation**: a local model adds a translation under each meeting line; the original is always kept.
- **Automatic updates**: signed releases are checked daily and installed when Phorminx is closed or idle, never during a recording. **Restart to update** in Settings installs right away.
- **Branded installer**: opens a guided setup that can prepare everything in one run.

## Fixed

- The tray and launcher showed a generic Windows icon instead of the Phorminx mark.
