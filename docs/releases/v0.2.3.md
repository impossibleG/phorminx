# Phorminx 0.2.3

Released 2026-10-18

A review panel, a prompt library, investigations and peer-to-peer messages.

## New

- **Review panel**: open the last dictation, edit it, reformat it, copy it, or replace the inserted text.
- **Live text** in the status pill while you dictate.
- **Formatting passes**: run AI formatting more than once, each pass refining the last.
- **Prompt library**: named, tagged, versioned prompts. Type `@` in any instruction field to insert one; it shows as a chip.
- **Investigations**: collect text, screenshots, links and voice notes as cards, see them as a chronology or a diagram, and ask the assistant, which cites your cards. Screenshot text is read by local OCR.
- **Messages**: peer-to-peer messaging over Tor onion services, off by default.

## Better

- New starter defaults: Accurate dictation with two-pass custom formatting.

## Fixed

- Saving settings no longer closes the app or makes it stop responding.
- Instant (Vosk) recognition no longer reports "no speech" after a quiet start.
- Custom formatting rewrites as instructed instead of barely changing the text.
- Settings written by a newer version no longer prevent Phorminx from starting.
