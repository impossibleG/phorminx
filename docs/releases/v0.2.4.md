# Phorminx 0.2.4

Released 2026-10-22

Benchmarks, one way to pick models, a Feedback page and steadier meetings.

## New

- **Benchmarks**: see which engines and models are fastest and most accurate for each feature, and use or download a benchmarked model in one click.
- **Model picker**: every place that needs a model opens the same searchable list, showing what is installed, what fits that feature and what you can install right there, with progress.
- **Feedback page**: see the reports and comments you sent, get told when a report is solved, take your comments down from the website, and tidy a report up before sending.
- **Action editor**: actions are set up in four steps, with a progress bar and help for each field.
- **Setup & repair**: run setup again at any time and see what each feature needs.

## Better

- Live translation picks its target language from a list.
- The meeting companion shows the original text of lines that have no translation yet.
- If a meeting input falls behind, it restarts by itself instead of staying off for the rest of the meeting.

## Fixed

- Meetings and dictation no longer say "workspace is busy".
- The meeting transcript no longer adds empty lines during silence.
- Installed models are no longer shown as "not installed" when Ollama is slow to answer.
- Setup & repair, Models and Feedback scroll when their content does not fit.
