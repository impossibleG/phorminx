# Architecture decisions

The `ADR-*.md` files preserve the project's design decisions and their evolution.
They are historical records, not a promise that every early proposal or default
still describes the current application. Later decisions supersede earlier
ones; consult the source and current settings for exact behavior.

Topics include the Rust desktop architecture, capture and insertion safety,
settings, local persistence, optional Ollama formatting, resident recognition,
rolling dictation, and transactional setup.

For current build and test commands, use [DEVELOPMENT.md](DEVELOPMENT.md).
For the product overview and privacy boundaries, use the [README](../README.md).
