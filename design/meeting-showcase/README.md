# Meeting companion design proof

Open [index.html](./index.html) in a browser. This is a local, synthetic, visual-only showcase for the **separate companion window**. It is not a proposed replacement for the main Phorminx workspace and does not capture audio, run models, or make network requests.

The companion has three in-window views:

- **Transcript:** source-labeled conversation with Original, Both, and Português presentation.
- **Together:** the transcript and assistant side by side, with the divider itself draggable.
- **Assistant:** commentary, conversation, and a fixed composer with room for the response.

Use the controls above the window to compare wide and compact dimensions and both existing Phorminx themes. The compact window shows one pane at a time; Together is available when wide. The source switches, commentary switch, language control, Hide, Finish, composer, and divider are interactive demos only. All copy is example content.

The main application's Live session, Saved sessions, and Meeting settings tabs remain separate. This showcase changes no application behavior.
