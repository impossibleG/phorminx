BEFORE CONTINUING

Prepare your local starter

Phorminx will download verified speech assets, install Ollama and a small local language model, and install Vulkan if Windows needs it. Anything already installed is kept and skipped. Windows may ask for administrator approval for Vulkan. Existing text and settings are preserved; this can take several minutes and use substantial disk space.
